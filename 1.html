1. Интернет

Интернет
Всемирная система объединённых компьютерных сетей, построенная на использовании протокола IP и маршрутизации пакетов данных. Интернет образует глобальное информационное пространство и служит основой для Всемирной паутины.
Наверх

2. Браузер

Браузер (веб-обозреватель)
Программа для просмотра веб-страниц. Популярные браузеры: Google Chrome, Mozilla Firefox, Microsoft Edge, Opera, Safari.
Наверх

3. Сервер

Сервер
Аппаратное или программное обеспечение, которое предоставляет доступ к ресурсам другим компьютерам по сети. Веб-сервер отдаёт браузеру страницы сайта.
Наверх

4. HTML

HTML (HyperText Markup Language)
Стандартный язык разметки документов во Всемирной паутине. С его помощью создаётся структура веб-страницы: заголовки, абзацы, списки, таблицы, ссылки и изображения.
Наверх

5. URL

URL (Uniform Resource Locator)
Унифицированный указатель ресурса — адрес веб-страницы или файла в интернете. Пример: https://example.com/page.html
Наверх

6. HTTP

HTTP (HyperText Transfer Protocol)
Протокол передачи данных. Изначально использовался для передачи гипертекстовых документов, сейчас — для любых данных. HTTPS — защищённая версия с шифрованием.
Наверх

7. Доменное имя

Доменное имя
Символьное имя для идентификации областей в сети Интернет. Пример: example.com, mail.ru
Наверх

8. Хостинг

Хостинг
Услуга по размещению и хранению файлов сайта на сервере, который подключён к интернету круглосуточно. Бывает виртуальный, VPS, выделенный.
Наверх
